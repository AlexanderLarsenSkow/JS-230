Rules:
  first Name, lastName, password, and email are all required
  phone number optional
  passwords must be ten characters long
  phone numbers must use US style: 111-222-2233
  emails conform to constraint validation pattern .+@.+

  Implementation Notes:
    required
    maxlength and minlength
    min max step
    pattern (regex)

  :user-invalid can be used to style anything that is invalid
  :user-valid can be uesd to style anything that is valid

  :valid / :invalid as well

  Important JS Properties in Constraint Validation API
    - validationMessage
    - validityState
    - patternMismatch: returns true or false if pattern is not matched
    - tooLong: returns true if too long (over maxLength)
    - tooShort: returns true if too short (under minLength)
    - valid: returns true if all valid
    - valueMissing: returns true if missing and is required in HTML

  Events:
    blur focusout on the form, checks if the target meets the requirements.
      -blur also removes the error message at the top of the form IF no more errors.
    submit event, puts error message at very top if something required hasn't been met.
      - the submit event should also make every invalid input red bordered and put an error message
        next ot it.
    focus event on the form, removes red / green styling and any error messages if they exist
    
    make a span element that has the error message as its content.
          <span class="error-message">Error Message that is very long</span>

    checkValidity()
      returns true if element's value has no validity problems.
        - if invalid element, fires invalid event on element



Functionality:
  - When a form field loses focus, validate the field against the validation rule for hte field.
    value not valid, display a red error message to the right of hte field. add red border too
  - When a field with an error regains focus, the message should disappear
  - It should not reappear after correcting the error.
  - Clicking submit:
    - don't send the form to the server if it has any validation errors. Instead, display an error
      at the top of the page that says "Fix errors before submitting this form"
  - form validation message should disappear when user corrects all fields with an error.
